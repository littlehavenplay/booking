🎂 Issue a birthday code (custom dates)

Automatic birthday codes already cover the child's whole birthday week (Sunday–Saturday) and are emailed a week ahead — so a birthday on a closed day is already handled. Use this tool only for a custom date range (e.g. extending the window). It's a 100% free Open Play admission for that child over whatever dates you pick. 🎒 Classroom free-admission codes

Generate a batch of one-time codes for a classroom. Each code makes one child's admission free at the correct price automatically (baby room or preschool), and can't be combined with other discounts. Families enter the code in the "Free-visit reward code" box when booking online. Hand a unique code to each family.

If a batch you already printed/handed out isn't working, use this — it forces those exact codes back to valid (unused, unexpired) without changing the codes themselves, so nothing needs to be reprinted. Paste the codes one per line, or leave blank to fix every code already on file for that classroom.

⚠️ Codes that failed at checkout

Every time a family's free-visit, birthday, or classroom code doesn't go through, it's logged here with their name/email/phone from the booking form — plus you get an email the moment it happens. Use this to follow up directly instead of guessing who tried. Dismiss an entry once you've reached out.

🗓️ Weekday special (automatic)

An always-on discount for slow days — no code needed, applies itself the moment someone picks that date. Pick which days, which admission types it covers, and a percent or dollar amount. Turn off anytime.

🎉 Party booking promo (one-day special)

Runs off the date the party is booked, not the party date — book on Labor Day for a November party and it still counts. The deposit never changes; the discount comes off the final balance you settle at the end of the party. It only locks in once you mark the deposit paid, so no deposit means no discount.

👨‍👩‍👧 Family master code

Owner only. One code that zeroes the entire admission total on a normal online booking, whatever the headcount. Never expires, unlimited uses. The booking still takes real capacity, still collects names and phone, still sends a confirmation, and still records the visit — it just isn't paid for and earns no punches.

⚠️ Treat this like a key to the front door. Anyone who has it can book free play. You get an email every single time it's used, and rotating it kills the old one instantly.

📌 Promotions & Flyers

A simple ongoing post — just an image and an optional caption, like a Facebook/Instagram post. No date, no requirements, nothing to expire — it stays up on the Events page until you remove it. Select more than one image at once to post them all in one go — each becomes its own separate post, sharing the same caption if you write one. Use this for a weekday discount flyer, an extended-hours graphic, anything that should just stay posted. For anything needing registration or a specific date, use "Upcoming events" below instead.

📧 Newsletter

Send a promotion, event or closure update to everyone who opted in through the pop-up on your website. Write your message, add a photo if you like, then send it now or schedule it for later.
