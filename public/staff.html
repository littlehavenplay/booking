🎂 Birthday club

Children whose families shared a birthday when booking online. A festive email with a free-admission code goes out automatically one week before each birthday, plus a short reminder on the birthday itself — the code works on the birthday only, one use. Session capacity & blocking

Block a session, limit its capacity, or reserve it for a private party.

Limits how many children can book this session online — the website shows the reduced spots, then FULL. Set 0 to accept none.

Block hides a session from online booking (shows Unavailable). Set capacity caps how many kids can book it (shows FULL when reached). Walk-ins you log in person still work either way. Release restores normal capacity.

🎒 Classroom free-admission codes

Generate a batch of one-time codes for a classroom. Each code makes one child's admission free at the correct price automatically (baby room or preschool), and can't be combined with other discounts. Families enter the code in the "Free-visit reward code" box when booking online. Hand a unique code to each family.

If a batch you already printed/handed out isn't working, use this — it forces those exact codes back to valid (unused, unexpired) without changing the codes themselves, so nothing needs to be reprinted. Paste the codes one per line, or leave blank to fix every code already on file for that classroom.

⚠️ Codes that failed at checkout

Every time a family's free-visit, birthday, or classroom code doesn't go through, it's logged here with their name/email/phone from the booking form — plus the owner gets an email the moment it happens. Use this to follow up directly instead of guessing who tried. Dismiss an entry once you've reached out.

Weekly hours

Your standing hours, set day by day. Each day's last admission is automatically 1 hour before that day's close. These control bookings and show on your website.

Seasonal hours

Off by default — using your Weekly hours.

A temporary day-by-day override for a date range (e.g. summer). Within these dates it replaces your Weekly hours and shows as seasonal hours on the website. It turns off on its own after the end date.

Closures & hours

Closing a date all day automatically shows a notice on your website (banner + store hours) and blocks bookings — no separate news post needed. It clears itself once the date passes.

Blocks online booking for that date/time automatically. "Last admission 12 PM" keeps the 11–1 PM session bookable. Existing bookings aren't cancelled; in-store walk-ins still work.
