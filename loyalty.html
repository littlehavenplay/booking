🎈 Loyalty & Punch Cards

Full loyalty card management — create, punch, edit, and search

📄 Import waiver info from WaiverMaster

Upload a WaiverMaster CSV export to reconcile waiver-signed dates and adult names onto existing loyalty cards, matched by phone number AND the child's name. If a child appears in more than one submission, every guardian from every submission is combined onto their card — nobody's name gets dropped. Never creates a new card. Flags (without touching) any card whose phone number appears in the file but whose child doesn't match any submission for that number — a sign the card may be linked to the wrong family. Also shows every card in the whole system with no waiver on file at all, so nothing gets missed.

📅 Backfill visit history from past bookings

One-time tool (safe to run more than once — it never adds the same visit twice). Scans every past booking that was actually checked in and adds it to that child's existing loyalty card. Never creates a new card, never touches waiver info — only adds visit history.

🎈 New loyalty card / punch

Already have a card? Just search their name in Loyalty customers below and tap ➕ Punch — no code lookup needed. Use this box only for a new regular (it creates their card).

One punch per PAID visit, per child (confirm the name on WaiverMaster first). After 7 punches the 8th is free — a reward code emails automatically. Don't punch legacy prepaid redemptions.
